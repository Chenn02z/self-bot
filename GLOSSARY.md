# Self-bot

A personal PWA bundling daily-life tools (spending, habits, and future modules) behind one login.

## App

**Module**:
One self-contained tool in the app (Spending, Habits, Stocks), with its own screen.
_Avoid_: App, feature, tab

**Home**:
The landing screen that lists every module and opens into each.
_Avoid_: Dashboard, launcher, hub

## Habits

**Habit**:
Something the user wants to do a set number of times each day.
_Avoid_: Goal, routine, task

**Target**:
The number of check-ins per day that makes a habit done for that day. A yes/no habit has a target of 1.
_Avoid_: Goal, quota

**Check-in**:
One recorded occurrence of a habit on a given day.
_Avoid_: Log, tick, track, entry

**Streak**:
The number of consecutive days, ending today or yesterday, on which a habit met its target.
_Avoid_: Run, chain
